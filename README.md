# IntraCblFitnessApp


I have set up the project such that the Main branch cannot be merged to with out the approval of 3 other members of the group. This is to make sure that the Main branch is stable and can be relibly used as a fall back incase any individual's branch becomes unstable or requires a roll back.

I suggest that you each create your own branch to work from, this way you can work on your own aspect of the project. I have already done so for myself as you check and see.

This can be done by cloning the repo to your local device and navigating to it in the terminal and running the following command:

```
git branch <Your name>
git checkout <Your name>
```
From there you should be able to push and pull from your own branch.
